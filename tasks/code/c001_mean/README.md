# stats

A small statistics helper module.

## `mean(numbers)`

Returns the arithmetic mean (average) of a non-empty list of numbers: the sum of
the numbers divided by how many numbers there are.

Examples:

- `mean([2, 4, 6])` returns `4.0`
- `mean([7])` returns `7.0`
- `mean([1.5, 2.5])` returns `2.0`

Works with integers, floats and negative numbers.
